Enjambre autónomo de agentes SRE orquestados por Qwen Cloud (qwen-max) sobre infraestructura de Alibaba Cloud ECS en Virginia. El sistema diagnostica fallos de red, base de datos y seguridad en tiempo real sin intervención humana, registrando cada decisión en MongoDB y exponiendo un dashboard web en vivo.

Desplegado en instancia ECS ecs.c9i.large (us-east-1) con VPC, firewall y aprovisionamiento 100% automatizado via SDK de Alibaba Cloud.
