# Visuals drop zone

Put site images here as PNG/JPG/WebP files and reference them from `src/data/site.ts`.

Recommended names:
- `hero-innerchispa.png`
- `pc-doctor-case-study.png`
- `workflow-whatsapp.png`

Workflow:
1. Copy the image into this folder.
2. Add or update an entry in `src/data/site.ts` under `visuals`.
3. Rebuild the site.

This keeps the image handling simple, local, and reusable.
